# 原版直达 v0.1.0-preview.1

**原版装好，PCL 照用。**

不用换掉熟悉的 PCL，也不用接触命令行，就能完成 Minecraft Java 原版安装。

本版为 **技术预览（Pre-release）**。下面的本机验证记录与 GitHub Actions 构建记录共同说明当前验证范围。

## 可以做什么

- 中文图形界面：确认 PCL 使用的 `.minecraft` → 选择原版正式版 → 安装 → 回到 PCL 选版本。
- 从官方清单获取版本并按版本号筛选，下载文件按官方清单校验 SHA-1。
- 安装过程显示进度并支持取消；同名版本不覆盖，共享文件校验冲突时停止。
- Windows x64 自包含包，无需另装 .NET SDK。解压后运行 `VanillaReach.exe`，请保留同目录许可文件。

## 已有验证证据

- 本机隔离目录安装原版 `26.3`，独立核验 5,225 个文件，PCL `2.99.0.0` 能识别该版本。
- 发布准备时执行自动化测试：43 通过，0 失败，0 跳过。
- 本地预览包完成构建和窗口启动检查；Release 附件由 GitHub 的 Windows 构建环境重新测试、构建和打包，与本地 EXE 的哈希可能不同。

这些记录**不包含实际进入游戏、干净 Windows 系统或多设备运行验证**。历史安装记录见 [验证报告](https://github.com/qianmozhuoliunian/-pcl-vanilla-helper/blob/v0.1.0-preview.1/docs/verification/mvp-results.md)，命名和发布包核验见 [发布检查](https://github.com/qianmozhuoliunian/-pcl-vanilla-helper/blob/v0.1.0-preview.1/docs/release-review.md)。

## 下载与使用

普通玩家请从本页的 Assets 下载附件 `VanillaReach-win-x64-preview.zip`，完整解压并运行里面的 `VanillaReach.exe`。不要下载 GitHub 自动生成的 Source code ZIP 来寻找程序。

附件 `SHA256SUMS.txt` 用于核验两个 ZIP 下载文件，值由构建对应包的 GitHub Actions 自动生成。[三步使用说明](https://github.com/qianmozhuoliunian/-pcl-vanilla-helper/blob/v0.1.0-preview.1/README.md#三步安装原版)

## 当前限制

- 使用官方源，速度和可用性取决于网络；没有国内镜像或加速承诺。
- 只支持原版正式版；不包含 Mod 加载器、整合包、Java 管理、账号登录或游戏启动。
- 失败后可重试，但没有自动修复、断点恢复或完整回滚。同名版本会停止安装。
- 取消时会尝试清理临时目录，已提交的有效共享文件可能保留；异常退出可能留下临时目录。
- 安装期间请避免其他程序同时修改相同目录。软件不提供游戏游玩授权。
