## 本次改动

- 固定侧栏导航，右侧页标题、游戏目录卡片和操作区；好友页按原有规则隐藏游戏目录。

- 整合包仍按搜索、发布版本检查、独立实例三个步骤；图片、名称和简介继续取自 Modrinth。账号窗口、邀请与项目简介采用同一字体与卡片。
- 保留 Windows 原生窗口标题栏及系统字体，没有下载 Apple 字体、图标或系统资源，没有引入第三方 UI 框架。此版本为浅色设计。

## 实际限制

- 比例渲染不是完整的多显示器/真实 Windows DPI 切换测试。原生检查使用路由键盘事件与自动化接口，不等同于所有实体键盘、读屏器及输入法组合的人工测试。
- 未验证干净系统、进入游戏或公网好友服务；当前好友仍需配置服务，原有本机套件保持技术预览边界。
- 原有好友列表自动重建时的行按钮焦点丢失仍是已知小问题，本轮未修改好友同步逻辑。
- 构建发布不表示已做依赖漏洞审计；程序包应连同现有许可与隐私说明分发。
