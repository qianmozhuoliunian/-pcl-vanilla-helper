## 实机验证限制

电脑操作工具能读取新窗口的控件树，但截图呈黑色；刷新窗口并重试后两次返回 `failed to activate captured window`，因此停止该窗口的输入。鼠标、键盘焦点和运行中状态仍待实机验证。

独立审查的一项待确认问题：原生主题对主按钮悬停/按下背景的处理可能影响白字对比，尚未观察到确定缺陷，记录待验证。此次保留系统控件模板，避免引入新的自定义模板风险。

整合包完整在线安装与 PCL 识别的验证未因本次 UI 检查而视为完成。当前产物仅为本地 UI 技术预览，不发布 GitHub 新版本。
