# Kimi 协作界面优化

2026-10-23，用户授权操作其 Kimi 桌面版并要求继续。已取得 Kimi 对现有界面结构的评审。发送内容为产品目标和布局、绑定说明，不含私人目录、账号或存档。

采用其推荐的“固定底栏 + 三段分组”路线，沿用浅色蓝色设计。四步向导需要新导航状态，留待后续。本轮是既有整合包设计中界面部分的完善。

主窗口采用紧凑标题、目录确认栏、占余下高度的页签。各页 Grid 分为星号内容行和 Auto 底栏：内容可滚动，取消、安装、状态与进度固定可见。整合包正文分为找包、选版本并检查、确认独立实例。

共享样式使用 36 DIP 控件最小高度，20/14/13/12 DIP 标题、分组、正文与辅助字号，8/16/24 DIP 间距。保留系统模板与键盘焦点。派生主按钮继承隐式 Button 样式；安装时禁用表单容器，取消在容器外。

保留全部绑定、事件、目录确认、安装互斥和同名保护。校正 Kimi 的建议：取消用中性色；不新增重试和实时同名检测；不以 0% 推断未知进度；原版搜索继续即时筛选。

验收：Release 构建和既有测试通过；默认及 560×580 窗口下正文可达，底栏不被正文带走，无横向溢出；原生字段可用键盘操作。UI 验证不替代真实整合包安装和 PCL 识别验证。
