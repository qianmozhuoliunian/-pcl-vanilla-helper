# 原版直达：macOS 浅色桌面风格

用户目标：界面像苹果系统一样简洁、有质感，普通玩家仍能容易完成安装。此次为现有 WPF 界面的视觉与布局优化，采用用户此前委托设计判断的协作方式直接实现可逆改动。

## 设计选择

- 采用 macOS 工具应用常见的侧边导航、浅灰背景、白色分组卡片、少量蓝色强调和清晰字体层级。保留 Windows 原生标题栏、移动、缩放、关闭及键盘操作。
- 现有 WPF 原地优化：不引入 WebView/第三方 UI 框架，不下载 Apple 字体、图标或系统资源。图标由简单原创线条组成，文字使用已安装系统字体。
- 比较过仅替换颜色（改动小但默认控件仍割裂）与全面玻璃/自绘窗口（开发和适配代价高）；选择统一控件模板与页面分组。无装饰性动画或持续模糊。
- UI/UX 检索得到通用极简风格；其营销网页结构、金色配色、网页字体不适合本工具，不直接采用。项目使用以下桌面设计取值。

## 视觉约定

背景 #F5F5F7，侧栏 #ECEEF2，卡片 #FFFFFF，主要文字 #1D1D1F，辅助文字 #62636B，强调蓝 #006EDB；卡片圆角16、控件圆角8，4/8倍数间距。字号13/14/16/24，正文常规字重，标题半粗。

左侧三项：原版安装、整合包、好友。右侧页标题、目录卡片、页内容；好友页隐藏目录卡片。主要安装按钮固定在可见底部，错误区域可滚动，长内容不横向溢出。整合包保留检索/版本检查/独立实例三步，来源资料不改写。

## 边界及验收

- 不改变安装器、文件写入、目录确认、来源校验、账号协议和服务部署。
- 导航在安装锁持有期间不能切换；解锁后恢复。现有事件和选定整合包绑定不丢失。
- 按钮悬停/按下/禁用/键盘焦点清晰；密码框与文本框一致；下拉框键盘与弹出选择正常；控件保留原生自动化语义。
- 默认及最小窗口可用，125%/150%比例渲染检查。必要区域滚动，内容不覆盖固定按钮。
- 构建、现有自动化测试、原生导航/模板交互检查、三页与弹窗真实 WPF 渲染后交付本地预览；不宣称公网好友服务可用。
