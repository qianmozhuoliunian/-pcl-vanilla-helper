# 整合包检索、图标与真实简介

用户要求优化检索，在名字旁展示项目相关图片，点开有简单介绍，资料不得编造。采用现有 Modrinth 公开 API；保留 Fabric 安装范围。

## 路线

采用列表图标 + 原生详情窗口：保留当前选包和安装操作，简介窗口展示发布者原文、实际下载量、项目声明版本及来源链接。把全文内嵌进结果会拉长安装页；网页嵌入会新增框架和外部脚本，不采用。

## 需求与边界

- 支持自动排序（空词按下载量、有词按相关度）以及显式相关度、下载量、最近更新排序；回车搜索。
- 一次提交形成搜索快照；分页沿用快照。修改条件提示重新搜索，搜索失败清理旧结果。下一页和上一页在边界禁用。
- MC 版本贯通版本接口及本地防御筛选；更改 MC/测试版选项清理旧版本和过期预览。
- 名字旁展示搜索结果 icon_url 指向的项目图标。只接受 HTTPS、无凭据、无片段、默认端口且在 Modrinth CDN 的地址。
- 图标按需加载，最多三路并发，响应上限 2 MiB，超时 20 秒，缩略解码并限制尺寸；内存缓存有界。失败显示占位，不影响搜索和安装。
- 点击标题/简介按钮、列表回车或双击打开详情。只展示接口 description 原文；为空写“项目未提供简介”。不生成图片、摘要或中文翻译，不将项目全部 MC 版本标为 Fabric 版本兼容承诺。
- 明确 Modrinth 来源，可主动打开固定 modrinth.com 的该项目页面；不执行远程 HTML/Markdown。
- 全程保留现有目录确认、安装互斥、取消和已有文件保护；不接入新下载源。

## 验收

假传输层验证排序、编码、分页快照、版本贯通、缺图/缺简介和越界 URL；受控图片传输验证超限、坏内容和取消；真实 API 验证一例搜索/详情/图标；WPF 构建和最小尺寸渲染通过；完整回归测试通过。测试数据必须明确为测试夹具，不用于产品实际显示。
