# 整合包检索与项目资料（开发预览）

1. 在“整合包”输入项目名称，可填 MC 版本筛选；按 Enter 或点搜索。只检索 Modrinth 的 Fabric 整合包。
2. 排序可选自动、相关度、下载量、最近更新。自动模式在有关键词时按相关度，空关键词时按下载量。
3. 结果名字旁显示该项目提供的图标、发布者、简介和下载量。点击标题或“简介”打开原生详情窗口，列表 Enter/双击也可打开。
4. 详情保留项目发布者原文，提供 Modrinth 来源入口。名称、图标、描述、统计和版本都来自接口，不生成替代图片、中文翻译或推荐介绍。缺图或缺简介会明确提示。
5. 选择项目后获取包版本；MC 筛选会继续应用到版本列表。更改 MC 或测试版选项会清除旧版本和预检。包安装兼容性以具体版本及包索引为准，项目全部 MC 版本不等同于全部 Fabric 版本保证兼容。
6. 修改搜索条件后重新搜索再翻页。分页使用已提交条件，失败时清理旧结果，边界页按钮禁用。

图标源可能返回 WebP。若系统不支持，工具尝试项目 API 提供的原始图片地址；不猜测地址。仍无法显示时用文字占位，不阻止操作。网络或来源缓存可能使搜索页和详情页的下载统计暂时不同，二者各自显示其接口返回值。

## 开发者验证命令

```powershell
dotnet test tests/PclVersionBridge.Tests/PclVersionBridge.Tests.csproj
dotnet run --project tests/PclVersionBridge.UiChecks/PclVersionBridge.UiChecks.csproj
```

后者为 Windows/WPF 离线检查，验证解码、来源提供的原图后备、缓存和细长图片缩略上限，不访问网络。其图片和项目均是明确的测试夹具，应用正常界面从不使用这些测试资料。
