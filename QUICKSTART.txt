原版直达 · VanillaReach
原版装好，PCL 照用。

这是面向 PCL 玩家的非官方 Minecraft Java 安装助手，当前为技术预览。
与 PCL、Mojang、Microsoft 无隶属或认可关系。

怎么用
1. 解压整个程序包，双击 VanillaReach.exe。
2. 在 PCL 的游戏目录设置中确认当前 .minecraft 路径。
3. 在原版直达中浏览并选择相同的目录，点击“确认目录”。
4. 选择原版正式版，点击“开始安装”，等待完成。
5. 回到 PCL 刷新或重新进入版本列表，选择该版本。

Windows x64 自包含包不要求另装 .NET SDK。安装需要连接官方源，速度取决于网络。
Java、账号和游戏启动继续由 PCL 处理；本工具不提供游戏游玩授权。
当前源码另支持 Modrinth Fabric 整合包搜索、来源图片与简介、本地 .mrpack 导入。
在“整合包”选择项目与具体发布版本，先检查内容，再确认安装到新的独立实例。
仅支持 Fabric + Minecraft Java 原版正式版；不支持 Forge、NeoForge、Quilt、快照、自动修复或回滚。

“好友”为可选功能，需另行配置好友服务，默认没有公共服务器。
好友账号独立于 PCL/Microsoft；经双方同意后，可分享指定发布版本的整合包卡片。
原版和整合包安装无需登录好友账号；收到卡片不会自动安装。
本说明对应当前源码，已发布 v0.1.0-preview.1 下载包只有原版安装与旧界面。

已有同名版本或哈希冲突会停止安装，不会自动覆盖。安装时避免其他程序同时修改目录。
正常取消会尝试清理临时目录；已提交的有效共享资源可能保留。
目前已在本机验证 26.3 安装和 PCL 2.99.0.0 识别，未验证实际进入游戏及干净 Windows。
